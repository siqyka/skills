# 接手协议（收到交接文档之后）

本文件是 `SKILL.md` 接收模式（B）的完整展开。**收到带 handoff 路径的任务时，先读完这一份，再动手。**

核心判断只有一句：**文档里的路径、命令、结论都是上一个会话替你付过学费的，重复探索等于把学费再交一遍。**

## 执行顺序

1. **一次性读完文档**，文档里引用的其他文件（模板里的 `references`、产物、规格）只按需再读，不要顺着链接把整棵树都读了
2. **弹窗问临时文件清理**：读完、确认能接手之后、真正动手之前，问一次（见下节）。这不是可选项
3. **信任并复用**：写明的路径、命令、结论不再验证一遍；只对「明显会过期」的东西做一次轻量确认（`git status`、目标文件是否还在、端口是否还占着）
4. **不重走探索**：禁止遍历项目根、禁止「确认一下技术栈」、禁止 Hello World 试验；已有明确路径时禁止广域搜索
5. **缺信息就精确补读**：只读那一个目标文件，不回退到全量探索。每次读之前先明确「我要从这个文件拿什么」
6. **对齐当前消息**：文档目标与用户此刻的要求冲突时，以当前消息为准，并说明差异（哪一条变了、影响哪几步）
7. **完成后回报**：做了哪几步、验收项勾选情况、与原文档不一致的地方、剩余风险

## 收尾：临时文件清理（读完后、动手前的选择弹窗）

**触发时机**：读完文档、确认下一步方向之后、真正动手之前，只问一次。不要拖到任务完成才问，更不要在生成端（写总结的那一侧）问。此刻文档内容已经在本会话上下文里，所以才敢删。

**必须用选择弹窗，不要写成正文问句**：调 `ask_user_question`，一题三选项，每项写清后果；清单放进题干（用户看不见清单就没法选）。

```text
ask_user_question({
  questions: [{
    id: "handoff-cleanup",
    header: "清理交接文件",
    question: "交接文档已读完，以下临时文件要清理哪些？\n1. <绝对路径>（<作用>）\n2. <绝对路径>（<作用>）",
    options: [
      { label: "只删临时产物，保留交接文档（推荐）", description: "文档留着便于回查，本会话上下文被压缩后还能重读" },
      { label: "全部删除（含交接文档）", description: "文档内容已在上下文里；一旦上下文被压缩或换会话，就无法再读" },
      { label: "全部保留", description: "一个都不删，后续自行清理" }
    ]
  }]
})
```

执行顺序：

1. **汇总清单**：取文档「元信息 → 临时文件（待清理）」里的路径 + 本次接手过程中自己新建的临时文件（脚本、导出、缓冲目录、`.bak`）
2. **只读确认存在性**：`ls` / `Test-Path`；远端文件用 ssh 工具在远端查。已不存在的标注「已不存在」，不凭记忆报
3. **弹窗**（按上面的形状），清单一项一行，带作用说明
4. **按选择执行**：
   - 「只删临时产物」→ 保留 handoff 文档，删其余
   - 「全部删除」→ 删清单内全部（含 handoff 文档）
   - 「全部保留」/ 跳过 / 没答 → **一个也不删**，也不再追问第二次
5. **删除边界**：只删清单内、且确认为本次产生的路径。用户产物、引用清单里的交付物、git 跟踪的文件、清单外的任何路径一律不删。远端路径在远端 `rm`，不要本地误删同名文件
6. **回报一句**：删了什么、保留了什么、各自绝对路径，然后开始「下一步最小行动」

> 当前环境没有 `ask_user_question`（非 DSH 会话、或该工具被裁掉）时，才退化成正文问句；退化时同样先列清单再问，且必须等到回答，不许自作主张删。删除不可逆，顺序永远是「先列 → 弹窗 → 后删」。

## 三种常见误读

| 错误做法 | 后果 | 正确做法 |
|---|---|---|
| 把文档当参考，还是从项目根扫一遍 | 接手成本等于重做一遍，交接白写 | 只按文档给的路径深入 |
| 「验证一下文档说的对不对」全量复跑命令 | 半小时起步，还可能改动现场 | 只确认易过期项（git 状态、文件存在性） |
| 读完就闷头改，不问清理 | 临时文件无人认领，越积越多 | 动手前弹窗问一次 |

## 与原文档冲突时

- **事实冲突**（分支变了、文件被删）：以现状为准，在回报里点明差异，不要默默绕过
- **目标冲突**（用户此刻要的和文档写的不是一回事）：以用户当前消息为准，说明「文档 X 段已作废」，必要时提示重新出 handoff
- **找不到文档**：先确认路径拼写与盘符；仍找不到就问用户要最新路径，不要凭猜测重建内容
